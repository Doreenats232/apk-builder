# APK & EXE Maker

Upload a zip of your project → get an installable **APK** (Android Gradle project) or **EXE** (Node/Electron project).

- **APKMaker.exe** – Windows app. Runs the builder on your PC and shows a phone address + PIN. APK builds need JDK 17+ and the Android SDK (`ANDROID_HOME`) installed; EXE builds need Node.js.
- **APKMaker.apk** – Android remote. Enter the PC's address + PIN, pick a zip on your phone, download the result.

Phone access is protected by a PIN (builds run code on your PC) and can be turned off from the tray icon.
